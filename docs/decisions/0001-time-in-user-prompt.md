# 0001 时间与窗口信息放 user 段

- 状态：已采纳
- 相关代码：`pet/brain/context_builder.py`（`_time_prefix`、`_build_system`）、
  `pet/brain/llm_client.py`（缓存控制）、`pet/brain/prompts.py`

## 背景

服务端 prompt 缓存（`LLM_CACHE_PROMPT`）按**前缀**匹配。system prompt 里的任何一处变化都会让整段缓存失效。
而「当前时间」「窗口探测结果」「用户消息」「截图」每轮甚至每秒都在变。

## 决定

- system 段只放慢变量：身份、人格、记忆格式、感知说明、任务说明，以及按轮计算的感受/需求/记忆召回；
- 时间前缀、窗口内容、用户消息、图片全部放 user 段；
- 作息需求的文案里**不出现具体钟点**（「困了」「熬夜太久了」而不是「现在 23:47」），理由相同。

## 后果

- 缓存命中率显著提高，长对话的延迟与成本下降；
- 代价：system 里看不到精确时间，需要时间信息的行为都必须在 user 段或代码里处理；
- 后续若要往 system 里加「每轮都会变」的内容，先想清楚它会带来多少缓存开销。
