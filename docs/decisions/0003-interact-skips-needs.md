# 0003 即时交互不注入「你惦记着的事」

- 状态：已采纳
- 相关代码：`pet/brain/context_builder.py`（`_NEEDS_TASKS`、`_build_system`）

## 背景

三条任务路径共用一个 `_build_system`。`interact` 由单一事件触发（被抓、放下、站立窗口消失、投喂、
自觅食），预期输出是一两句即时反应；而「你惦记着的事」章节描述的是跨轮次的需求张力与建议做法。
两者放在一起时，模型容易把「我好饿，该去讨吃的」当成对「你被拿起来了」的回应。

## 决定

`_NEEDS_TASKS = frozenset({"autonomous", "chat"})`：只有自主决策与对话注入需求块，
`interact` 的 system 只保留感知段（动作表）、任务段、感受与最近事件。

## 后果

- 交互台词更聚焦，不会被长上下文带跑；
- 代价：抓起桌宠时它不会顺势提「我饿了」；若要改，只动这一个常量即可，并同步文档与测试。
